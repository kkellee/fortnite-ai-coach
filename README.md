# Fortnite AI Coach

Сайт игрока живёт на GitHub Pages. Чат рассчитан на серверную нейросеть Cloudflare Workers AI: посетителям не нужны ChatGPT, WebGPU или загрузка модели. Опубликованная версия останется прежней, пока изменения не отправлены на GitHub.

## Подключение AI

### Распределение моделей

Обычный чат и чтение скриншотов обслуживает Cloudflare Workers AI (Gemma 4). AI-разбор эпизода, итога и профиля отправляется в Gemini (`gemini-2.5-flash`), если на Worker настроен серверный секрет `GEMINI_API_KEY`; иначе в Groq (`qwen/qwen3.8-27b`), если настроен `GROQ_API_KEY`. Без обоих секретов разборы продолжают работать через Cloudflare. Ключи никогда не отправляются в браузер. Все провайдеры получают одни и те же правила тренера и ограниченный контекст профиля; чат также получает короткий текст уже сохранённых AI-разборов с пометкой, что это непроверенные выводы, а не факты. Модели не обмениваются памятью напрямую.

Создай API-ключ в Groq Console, затем в каталоге проекта выполни `npx wrangler secret put GROQ_API_KEY` и вставь ключ в терминал, когда Wrangler его запросит. Не помещай ключ в `dist/`, Git или переписку. После настройки проверь одну кнопку разбора: ответ сервера должен содержать `model: "qwen/qwen3.8-27b"`. Для чата и скриншота остаётся `@cf/google/gemma-4-26b-a4b-it`.

Если Groq недоступен, создай ключ Gemini API в Google AI Studio и выполни `npx wrangler secret put GEMINI_API_KEY`. После настройки ответ разбора должен содержать `model: "gemini-2.5-flash"`. Доступность и лимиты бесплатного уровня зависят от проекта Google; проверь их в AI Studio. На бесплатном уровне Google может использовать переданный контент для улучшения продуктов — это нужно учесть в уведомлении пользователям сайта перед включением Gemini.

Лимиты по IP в Worker: 20 сообщений чата, 3 AI-разбора, 1 чтение скриншота в сутки. Общий предохранитель в 9000 neurons относится только к вызовам Cloudflare через этот Worker; лимиты Groq задаются отдельно провайдером. Для большой публичной аудитории IP не равен игроку, поэтому понадобится авторизация и отдельный глобальный контроль расхода каждого провайдера.

Владелец проекта один раз создаёт бесплатный аккаунт Cloudflare и публикует Worker из `worker/index.mjs` с конфигурацией `wrangler.jsonc`. В каталоге проекта: `npx wrangler login`, затем `npx wrangler deploy`. Cloudflare выдаст адрес вида `https://fortnite-ai-coach-api.<subdomain>.workers.dev`. Вставить его в `dist/ai-config.mjs` как значение `AI_ENDPOINT` без завершающего `/`, затем отправить изменения на GitHub через GitHub Desktop. Посетители просто заходят на сайт и пишут в чат.

Бесплатный план Cloudflare Workers AI даёт ограниченную дневную квоту; после её исчерпания чат покажет ошибку до обновления лимита. Для владельца платная подписка не требуется, пока используется Free plan. Код Worker ограничивает размер сообщений и разрешает запросы с сайта проекта, но публичный адрес нельзя считать защитой от всех видов злоупотребления. При росте аудитории понадобятся лимиты и защита от автоматических запросов.

Текст беседы и профиль передаются Cloudflare для генерации ответа. Сайт пока хранит переписку локально в браузере. Видео, скриншоты и реплеи автоматически в AI не отправляются и не разбираются. Статистика Fortnite Tracker/Osirion автоматически не подтягивается; актуальная мета не проверяется автоматически.

## Проверка

`node --test tests/*.test.mjs` проверяет основные сценарии и контракт Worker с подставленной моделью. Настоящий ответ Cloudflare можно проверить только после подключения аккаунта и публикации Worker. `node server.mjs` запускает локальный сайт на `http://127.0.0.1:4173`.
